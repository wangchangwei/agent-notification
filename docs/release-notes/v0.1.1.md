# Agent Monitor v0.1.1

A read-only iPhone and Apple Watch companion for Hermes Agent on macOS. This release makes the probe a one-command install and brings the English interface, per-task titles and per-computer names that landed after `v0.1.0`.

## Install with one command

```sh
curl -fsSL https://github.com/wangchangwei/agent-notification/releases/latest/download/install.sh \
  | sh -s -- --url https://your-project.vercel.app
```

`install.sh` checks for Python 3.11 or newer, creates the virtual environment at `$HOME/Library/Application Support/Agent Monitor/.venv`, installs the wheel from this release, verifies it against `SHA256SUMS`, links `agent-monitor` into `~/.local/bin`, and registers this Mac with your bridge. The bootstrap token is prompted for without echoing it and the device credential goes to the macOS Keychain. Re-running the same command upgrades in place and never overwrites an existing registration.

Useful flags: `--plugin` also installs and enables the read-only Hermes observer plugin, `--owner-id ID` adds a second Mac to the same owner, `--service` writes the opt-in login service, `--version` and `--wheel` install another release or a downloaded file, `--force` reinstalls. `sh install.sh --help` lists them all.

After the install, finish with:

```sh
agent-monitor pair
agent-monitor run
```

Keeping `run` in a terminal is enough; `agent-monitor install-service` and the `launchctl bootstrap` command it prints start it at login. Restart the Hermes desktop app once after enabling the plugin so turn-level hooks are rewired. `INSTALL.md` in this release documents the manual wheel install for machines that cannot fetch the script.

## What changed since v0.1.0

- **One-command install**: `install.sh` is now published with every release and performs the virtual environment, checksum check, CLI link and optional registration in one step.
- **English interface and documentation**: the app, the CLI messages and the repository docs are English-only now. The `v0.1.0` Python package still carried Chinese state labels; this wheel is built from current `main`.
- **Task titles**: each task can show the first line of the request, with code blocks, links, e-mail addresses, paths and long tokens removed and the text capped at 24 characters. Set `send_titles: false` in the probe's `config.json` to stop sending titles entirely.
- **Per-computer names**: a Mac can be renamed from the phone (swipe its row, then the note action); every phone bound to the same owner sees the new name.
- **App icons** for the iPhone and watch apps.

## What is included

- **macOS probe** (`agent-monitor`): registers a Mac with the bridge, keeps a durable SQLite queue (7 days, 4,000 events), sends a heartbeat every 30 seconds and uploads state changes immediately.
- **Read-only Hermes plugin**: observes turn start, tool calls, human-input requests and resolution, sub-agent boundaries and session end. It fails open and never alters agent behaviour.
- **Serverless bridge**: FastAPI for Vercel Functions with an Upstash Redis REST adapter, one-time pairing codes, per-device revocation, sanitized event history and optional APNs delivery.
- **iPhone app**: SwiftUI, in-app QR pairing, live dashboard, task detail, cloud history clearing, sound and haptic on completion while foregrounded.
- **Apple Watch app**: read-only mirror of running, waiting and finished tasks, with its own copy of the credentials.

The bridge deployment is unchanged from `v0.1.0`: an existing Vercel project and Upstash database keep working, and an already registered Mac can be upgraded by running the installer again.

## Behaviour worth knowing

- A finished turn means the agent stopped producing for that turn. It does not mean the result was correct or accepted.
- Waiting for input, interruption and an ambiguous session end are reported as their own states; only an explicit failure signal marks a task failed.
- Computer connectivity and task state are independent. A stale heartbeat shows the Mac as disconnected and greys out its last known state.
- Notifications are best effort. APNs may delay, coalesce or drop a message, so opening the app always resynchronizes.
- The probe keeps 4,000 events for seven days; the server keeps the same window per device, and revoking a device deletes its history.

## Privacy

Only fixed state labels, opaque task and turn identifiers, elapsed tool time, a validated tool name, the agent brand, one scrubbed 24-character title and a generic push body leave the Mac. Prompts, tool arguments and results, file contents, paths and conversation text never do. The installer sends nothing except the release download.

## Known limits in this version

- Push notifications need a paid Apple developer account: a free personal team cannot sign the push entitlement, so a build installed with a free team shows status but receives no notifications.
- Builds signed with a free Apple team expire after seven days and must be reinstalled.
- No remote control of any kind: the app cannot approve, reply, cancel or resume.
- Vercel Hobby and Upstash Free have usage limits; this release does not meter quota in the app.
- `install.sh` targets macOS; it refuses to run elsewhere.

## Verification in this release

- The local Python suite passes (33 checks) and now also covers the installer: its pinned version must match the package version, the script must parse as POSIX `sh`, and unknown flags must be refused.
- The documented one-command install was run end to end against this release: download, checksum verification, virtual environment creation, package install and CLI link.
- iOS state model checks cover out-of-order events, shared task IDs, incomplete turns, heartbeat expiry and clock skew.
- Not verified in this release: real-device push delivery, and behaviour on a second Mac.
